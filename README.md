# Humanoid Core - 拟真生活状态引擎 (v2.4.3)

**一句话概括**：让人工智能拥有"身体"、"生活感"、"情绪"和"场景意识"的中轻量插件。

---

## 🚀 功能一览

| 模块 | 说明 |
|------|------|
| **动态日程** | 每日由大模型生成 24 小时生活日程，支持粒度调节（灵活/整点/半小时） |
| **精力系统（拟人化）** | 随机波动、午后微降（-2%）、每日保底，支持倍率调节，无惯性偏向 |
| **生理周期** | 模拟经期/卵泡期/排卵期/黄体期，支持完整/简洁两种描述风格 |
| **情绪系统** | 三维度（好感度/亲近欲/攻击性），用户交互驱动，精力与生理周期调制，50+情绪标签 |
| **实时天气** | 通过 OpenWeather 获取当前天气，作为聊天背景 |
| **三种聊天模式** | 完整注入 / 低侵入 / 纯情绪，自由切换 |
| **环境感知** | 可选择插件仅在私聊、仅在群聊或全部生效 |
| **聊天感知** | AI 能自动识别当前是群聊还是私聊，语气自动适配（可开关） |
| **星期几感知** | AI 知道今天星期几，日程生成和对话语境更贴合，`/时间` 也显示星期几 |
| **动态时区绑定** | 所有时间逻辑（日程、精力、午后节律）均基于配置的 `timezone_city`，不再硬编码 UTC+8 |
| **状态指令** | `/你的状态` 查看精力（含拟人描述）、生理、天气、日程概要、星期几、情绪标签 |
| **情绪档案** | `/好感度` 查看好感度/亲近欲/攻击性数值及情绪标签 |
| **情绪详情** | `/情绪详情` 查看详细情绪档案（含基线、轮次） |
| **管理员情绪管理** | `/重置情绪`、`/设置好感度`、`/批量好感度` |
| **时间查询（所有用户）** | `/时间 城市` 查询中日俄主要城市当前时间，同时显示星期几 |
| **昵称设置** | `/叫我 昵称` 让 AI 记住你的称呼 |
| **管理员查看昵称** | `/查看所有昵称` 列出所有用户设置的昵称 |
| **重置状态（管理员）** | `/重置状态` 一键恢复精力至80、生理周期重新计算 |
| **帮助指令** | `/拟人帮助` 列出所有可用命令 |
| **城市感知** | AI 会知道自己所在的默认城市及当前时间 |

## ✨ v2.4.3 更新内容

- **新增配置项 `mood_affection_override`**：指定QQ号的初始好感度覆盖，格式 `["QQ号:数值"]`，如 `["123456:100"]`
- **新增配置项 `mood_affection_delta_cap`**：单次好感度变化上限（1-10），默认 `3`，控制情绪变化速度
- **降低默认敏感度**：`mood_sensitivity` 从 `62` 降至 `28`，情绪变化更平缓自然
- **新增管理员指令 `/批量好感度`**：支持批量导入好感度，格式 `QQ号:数值, QQ号:数值` 或 JSON 数组
- **衰减保持平滑二次衰减**：不会直接归零，而是随时间缓慢回归基线

- **`_apply_mood_decay` 加锁**：避免并发写入 `state.json` 导致数据损坏

  - `/设置好感度 数值` - 手动设置好感度（管理员）

## ✨ v2.4.0 更新内容

- **新增情绪系统**：
  - 三维度：好感度（0-100）、亲近欲（0-50）、攻击性（0-50）
  - 每次用户说话，由 LLM 分析情感增量，动态调整情绪
  - 精力（高/低）和生理周期（经期/排卵期）作为调制因子
  - 情绪随时间向基线二次衰减，避免极端
  - 注入到系统提示词，AI 感知情绪标签，演绎更自然
  - 新增指令 `/好感度` 查看详细情绪档案

## ✨ v2.3.0 性能与逻辑优化（重要）

- **性能优化**：
  - 将同步阻塞的 `urllib` 替换为异步 `aiohttp`，彻底解决请求天气时的事件循环阻塞问题。
  - 精力计算改为**分段聚合算法**，消除分钟级循环。
  - 配置加载改为**缓存机制**，每次消息不再重复合并字典。

- **逻辑修复**：
  - **时区统一**：所有内部时间逻辑基于 `timezone_city` 对应的时区。
  - `energy_decay_rate` 增加**类型安全转换**。

- **健壮性增强**：
  - JSON 解析支持 ` ```json ` 代码块提取。
  - 增加 `requirements.txt`，显式声明 `aiohttp` 依赖。

## 常见问题

**Q：如何让日程符合我的角色设定？**  
A：在插件配置中从 `character_personality` 下拉列表选择一个人格。描述越具体，日程越贴合人设。

**Q：v2.3.0 的时区优化有什么影响？**  
A：现在所有时间逻辑（日程、精力、午后节律）都基于 `timezone_city` 配置，而不是固定的 UTC+8。如果你将城市设置为莫斯科，那么莫斯科时间 13:00~15:00 才会触发午后节律，与实际感知一致。

**Q：v2.3.0 性能提升明显吗？**  
A：是的。例如用户离线一天，旧版会循环 1440 次计算精力，新版只需按日程分段聚合，只需几次运算。同时天气请求不再阻塞事件循环，消息处理更流畅。

**Q：v2.4.3 的情绪系统怎么玩？**  
A：每次你说话，AI 会分析你的语气情感，动态调整好感度、亲近欲、攻击性。精力高或排卵期时情绪变化更敏感，精力低或经期时情绪变化迟钝。AI 会按情绪标签（痴迷/冷淡/愤怒等）演绎回复风格。

**Q：情绪数据是每个用户独立的吗？**  
A：是的，每个 QQ 用户有自己独立的情绪档案，互不影响。

**Q：如何重置情绪？**  
A：管理员发送 `/重置情绪` 即可重置为初始值，普通用户可等待情绪自然衰减回归基线。

**Q：v2.2.2 的"星期几感知"有什么用？**  
A：AI 在生成日程和聊天时会知道今天是星期几，比如周末会安排休息，工作日会侧重学习/工作，回复也更贴近生活节奏。

**Q：v2.2.1 的"聊天感知"是什么？**  
A：AI 会自动判断当前对话是在群聊还是私聊，并相应调整回复语气（群聊更活泼，私聊更亲密）。可以通过配置项 `enable_chat_awareness` 开关（默认开启）。

**Q：精力系统改了什么？**  
A：取消惯性（恢复与消耗完全由日程决定），午后节律从 -5% 改为 -2%，每日保底恢复至30，防止归零。

**Q：如何调节精力变化速度？**  
A：在 `energy_decay_rate` 中选择 0.5（半速）、1（正常）、2（双倍）或 3（三倍）。

**Q：如何让插件只在私聊或只在群聊生效？**  
A：在 `environment_mode` 中选择 `both`（全部）、`private`（仅私聊）或 `group`（仅群聊）。

**Q：日程一直不变化，总是同一套？**  
A：检查 `use_llm_schedule` 是否为 `true`；若为 `true` 但日志提示"无可用 Provider"，请确保已正确配置大模型。

**Q：如何重置今天的日程？**  
A：由管理员发送 `重置日程` 即可。请确保在 `管理员QQ列表` 中填写了你的 QQ 号。

**Q：如何重置精力和生理周期？**  
A：由管理员发送 `重置状态`，精力将恢复至 80，生理周期根据当前日期重新计算。

**Q：生理周期描述不准确或跳跃？**  
A：当前版本已修复周期日期的确定性生成和跨天更新锁保护，重启 Bot 不再随机重置。

**Q：天气无法获取？**  
A：请确认 `天气api_key` 填写正确、`weather_location` 格式为 `城市,国家码`（如 `Beijing,CN`），并检查网络连通性。

**Q：时间查询支持哪些城市？**  
A：支持中国（含各省会/直辖市及主要地级市）、俄罗斯（全部85个联邦主体）、日本（主要城市）。具体列表请参见上方 **"支持的城市列表"** 章节。

**Q：情绪系统的"攻击性"会不会让 AI 骂人？**  
A：攻击性只影响语气倾向（如讽刺、冷淡、愤怒），但不会突破你的 `character_personality` 人格设定。AI 仍然遵循你设定的人设框架。
