# Humanoid Core - 拟真生活与自然状态引擎 (v2.0.0)

本插件为 AstrBot 提供**去背景人设化**的底层拟人，整合动态精力、人格驱动的日程、天气与生理周期。

---

## ✨ v2.0.0 核心更新：低侵入模式

在之前的版本中，AI 的每一条回复都强制绑定了“当前日程活动”，导致无论聊什么，AI 都像在汇报工作，极不自然。

**v2.0.0 引入了“低侵入模式”**：
- **默认关闭日程活动注入**：AI 不再主动提及“我正在上班”、“我在家休息”等具体活动。
- **仅传递情绪与精力背景**：AI 只会接收到“当前精力较低”或“情绪倾向平淡”等抽象提示，作为回复语气的微调依据。
- **用户主动询问才透露**：只有当用户明确问“你现在在做什么”时，AI 才会参考日程回答，日常聊天回归自然。

你可以在插件配置中通过 **【聊天干预】是否将当前日程活动/位置注入提示词** 开关，自由切换模式。

## 核心特性

1. **多用户全局状态一致**  
   所有用户共享同一个物理世界的状态推演（精力、天气、日程、生理周期）。

2. **人格驱动的动态日程生成（LLM驱动 + 备用模板）**  
   - 根据你在配置中设定的 **角色人格（`character_personality`）** 生成符合人设的日程。  
   - 默认调用大模型（可指定 Gemini、GPT 等）每日自动生成全新的 24 小时生活日程。  
   - **灵活的时间粒度**：支持小时、半小时、20分钟、15分钟等，更贴近真实生活。  
   - 内置 **3次重试机制** + **超时控制**（60秒），网络波动自动重试。  
   - 支持从 Markdown 代码块中自动提取 JSON，**大幅提升解析成功率**。  
   - 若模型调用失败，自动降级至**基于日期哈希轮换的多套备用模板**。

3. **隐式生理周期（后台无感推算）**  
   - 后台零点自动跨天计算，前台仅隐式呈现生理体验描述。  
   - 周期起始日基于日期确定性生成，**重启 Bot 不会随机跳跃**。  
   - 描述会根据当前精力值动态微调。

4. **时段健康演进**  
   结合精力余量与当前时段活动，动态推演身体状况。  
   - **支持完整离线时长恢复**，断线多天也能准确回算精力变化。

5. **实时配置加载**  
   在 AstrBot 网页后台保存配置后，下一条消息立刻生效，无需重启 Bot。

6. **查看日程指令**  
   任意用户发送 `查看日程` 或 `今日日程`（无需斜杠），即可查看当天的完整日程表。

7. **重置日程指令（管理员）**  
   管理员发送 `重置日程`，可强制立即重新生成今日日程。需先在配置中设置 `admin_qq` 列表。

## 天气配置说明

天气接口平台：https://openweathermap.org

1. 注册账号，进入 API Keys 页面复制32位密钥。
2. 城市填写格式：`城市英文,国家码`，例如 `Beijing,CN` / `Moscow,RU`。
3. 免费额度足够个人使用，国内直连无需代理。
