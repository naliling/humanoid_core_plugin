# Humanoid Core - 拟真生活状态引擎 (v2.1.4)

**一句话概括**：让人工智能拥有“身体”和“生活感”的轻量插件。  

---

## 🚀 功能一览

| 模块 | 说明 |
|------|------|
| **动态日程** | 每日由大模型生成 24 小时生活日程（粒度灵活，可细至15分钟） |
| **精力系统** | 随活动自动变化，影响回复语气 |
| **生理周期** | 模拟经期/卵泡期/排卵期/黄体期，与精力联动 |
| **实时天气** | 通过 OpenWeather 获取当前天气，作为聊天背景 |
| **低侵入模式** | 不主动报日程，仅微调语气，聊天更自然 |
| **状态指令** | `/你的状态` 查看精力、生理、天气、日程概要 |
| **时间查询（管理员）** | `/时间 城市` 查询北京、东京、纽约等城市当前时间，可在配置中设置默认城市 |
| **昵称设置** | `/叫我 昵称` 让 AI 记住你的称呼 |
| **管理员查看昵称** | `/查看所有昵称` 列出所有用户设置的昵称 |
| **帮助指令** | `/拟人帮助` 列出所有可用命令 |
| **城市感知** | AI 会知道自己所在的默认城市（`timezone_city`），用于语气或地理参考 |

## 核心特性

1. **多用户全局状态一致**  
   所有用户共享同一个物理世界的状态推演（精力、天气、日程、生理周期）。

2. **人格驱动的动态日程生成（LLM驱动 + 备用模板）**  
   - 根据配置中的 **角色人格（`character_personality`）** 生成符合人设的日程。  
   - 默认调用大模型（可指定 Gemini、GPT 等）每日自动生成全新的 24 小时生活日程。  
   - **灵活的时间粒度**：支持小时、半小时、20分钟、15分钟等。  
   - 内置 **3次重试机制** + **超时控制**（60秒），自动重试。  
   - 若模型调用失败，自动降级至**基于日期哈希轮换的多套备用模板**。

3. **隐式生理周期（后台无感推算）**  
   - 后台零点自动跨天计算，前台仅隐式呈现生理体验描述。  
   - 周期起始日基于日期确定性生成，**重启 Bot 不会随机跳跃**。  
   - 描述会根据当前精力值动态微调。

4. **时段健康演进**  
   结合精力余量与当前时段活动，动态推演身体状况。  
   - **支持完整离线时长恢复**，断线多天也能准确回算精力变化。

5. **实时配置加载**  
   在 AstrBot 网页后台保存配置后，下一条消息立刻生效，无需重启 Bot。

6. **查看日程指令**  
   任意用户发送 `查看日程`，即可查看当天的完整日程表。

7. **重置日程指令（管理员）**  
   管理员发送 `重置日程`，可强制立即重新生成今日日程。需先在配置中设置 `admin_qq` 列表。

8. **状态、时间、昵称、帮助等便捷指令**（详见上方功能一览）。

## 💡 关于“低侵入模式” (`inject_activity_context`)

这个开关控制 AI 在聊天时是否“主动汇报”自己的状态：

- **开启（`true`）**：AI 会参考天气、位置、当前活动（如“正在上班”）来回复，适合需要陪伴感和生活细节的场景。
- **关闭（`false`，建议！）**：AI **不会主动提**日程活动和位置，只会根据精力、情绪和天气微调语气（比如累了就慵懒一点，天气冷了就提醒你多穿），聊天更自然，不会让人觉得在念报告。

> 即使关闭，天气信息仍然会被获取并作为语气背景。如果用户直接问“今天外面冷吗”，AI 依然能准确回答。

## 天气配置说明

天气接口平台：https://openweathermap.org

1. 注册账号，进入 API Keys 页面复制32位密钥。
2. 城市填写格式：`城市英文,国家码`，例如 `Beijing,CN` / `Moscow,RU`。
3. 免费额度足够个人使用，国内直连无需代理。

## 配置项说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `max_energy` | 【生理】精力上限值 | `100.0` |
| `enable_cycle` | 【生理】启用生理周期模拟 | `true` |
| `cycle_length` | 【生理】生理周期总天数 | `28` |
| `use_llm_schedule` | 【日程】是否启用大模型生成日程 | `true` |
| `schedule_provider_name` | 【日程】指定模型 Provider 名称 | `""` |
| `schedule_prompt_extra` | 【日程】额外偏好指导语 | `“工作学习与休息放松结合，日常节奏灵活自然，不刻意限定时段。”` |
| `character_personality` | 【人格设定】下拉选择已配置的人格 | `""` |
| `admin_qq` | 【权限】管理员 QQ 列表 | `[]` |
| `weather_enabled` | 【天气】是否启用真实天气 | `true` |
| `weather_api_key` | 【天气】OpenWeather API Key | `""` |
| `weather_location` | 【天气】目标城市 | `"Zelenogradsk,RU"` |
| `weather_refresh_minutes` | 【天气】刷新间隔（分钟） | `60` |
| `inject_activity_context` | 【聊天模式】是否让AI主动提及天气、位置和日程活动（关闭后仅微调语气） | `false` |
| `timezone_city` | 【时间】默认时区城市（同时作为AI感知的所在城市） | `"泽列诺格拉茨克"` |

## 常见问题

**Q：如何让日程符合我的角色设定？**  
A：在插件配置中从 `character_personality` 下拉列表选择一个人格。描述越具体，日程越贴合人设。

**Q：日程的时间粒度可以更细吗？**  
A：可以。支持半小时、20分钟、15分钟等灵活粒度。

**Q：日程一直不变化，总是同一套？**  
A：检查 `use_llm_schedule` 是否为 `true`；若为 `true` 但日志提示“无可用 Provider”，请确保已正确配置大模型。

**Q：如何重置今天的日程？**  
A：由管理员发送 `重置日程` 即可。请确保在 `管理员QQ列表` 中填写了你的 QQ 号。

**Q：生理周期描述不准确或跳跃？**  
A：当前版本已修复周期日期的确定性生成和跨天更新锁保护，重启 Bot 不再随机重置。

**Q：精力恢复太慢/太快？**  
A：精力变化速率取决于日程中的 `energy_rate` 值。若使用 LLM 生成日程，可调整 `schedule_prompt_extra` 提示词。

**Q：天气无法获取？**  
A：请确认 `天气api_key` 填写正确、`weather_location` 格式为 `城市,国家码`（如 `Beijing,CN`），并检查网络连通性。

**Q：时间查询支持哪些城市？**  
A：支持中国（含各省会/直辖市）、俄罗斯（全部85个联邦主体）、日本的主要城市。已包含 **泽列诺格拉茨克**。
