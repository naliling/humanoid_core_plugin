# Humanoid Core - 拟真生活状态引擎 (v2.9.0)

一个有自己的时间、会累会恢复、情绪会积累的AI生活引擎。  
联系作者：3881756548（重度依赖用户反馈与建议）

## 它是什么

- 每天有不一样的日程安排（由大模型生成）
- 精力会随着活动消耗和恢复（经期消耗更快，卵泡期更慢）
- 有生理周期（6个阶段，描述只提能量水平）
- 情绪会随着对话变化（好感度、亲近欲、攻击性）
- 会记住你让它生气的时刻（情绪日志）
- 可以切换人格（温柔、傲娇等，手动或定时）
- 天气会影响它的状态（接入OpenWeather）
- 知道今天是星期几，知道你所在城市的当前时间
- 你可以设定它对你的称呼
- 心情标签（如"疲惫但开心"），直观显示当前情绪
- 社交能量（影响回复热情，长时间对话会消耗）
- 夜间睡眠模式（深夜回复变短或主动提示休息）
- 热重载配置（/重载配置 指令，无需重启插件）
- 调试模式（输出详细日志，便于排查问题）
- 节日感知（内置公历节日 + 用户自定义，自动融入上下文）
- **新增**：支持指定模型 + 备用模型，生成日程时可按优先级选择
- **新增**：可配置重试间隔，避免连续请求失败时无等待

## 功能列表

| 模块 | 它在做什么 |
|------|-----------|
| **动态日程** | 每天用大模型生成24小时安排，工作/学习/休息/睡觉都有具体时间点 |
| **精力系统** | 早上恢复，白天消耗，经期消耗更快，卵泡期更慢，深夜剩5% |
| **生理周期** | 分了6个阶段，描述只提"能量高不高"，不提具体症状 |
| **情绪系统** | 好感度/亲近欲/攻击性，你每说一句话都在微调它的态度 |
| **情绪日志** | 它会记下"上次你惹我生气了"这种时刻 |
| **心情标签** | 根据情绪数值和精力生成可读标签（如"疲惫但开心"） |
| **社交能量** | 每条消息消耗，长时间不聊恢复，影响回复热情 |
| **夜间模式** | 深夜时段回复变短，或主动提示休息 |
| **多人格** | 两个人格配置，手动切或定时切，临时切可以设自动恢复时间 |
| **实时天气** | 接入OpenWeather，天气成为它日常状态的一部分 |
| **聊天模式** | 三种档位，你可以控制它"知道你多少状态" |
| **环境感知** | 私聊/群聊/全开都行，它会根据场景调语气 |
| **星期/时间感知** | 它知道今天是星期几，知道你在的城市几点 |
| **自定义昵称** | 你让它叫你什么，它就一直叫 |
| **热重载配置** | 修改配置后通过指令重载，无需重启插件 |
| **调试模式** | 输出详细日志，方便排查问题 |
| **节日感知** | 内置元旦、情人节、劳动节、国庆节等公历节日，用户可自定义补充 |
| **模型指定+备用** | 日程生成可指定首选模型，失败后可自动切换备用模型 |
| **重试间隔** | 生成日程失败时，等待指定秒数再重试，避免无间隔狂刷 |

## 配置项（新增部分）

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `schedule_provider_name` | 生成日程的首选模型 Provider（下拉选择） | 空 |
| `schedule_fallback_provider_name` | 备用模型 Provider（首选不可用时自动切换） | 空 |
| `schedule_retry_interval_seconds` | 生成日程失败时的重试间隔（秒） | 2 |
| 其他配置项见 `_conf_schema.json` | | |

**模型选择逻辑**：
1. 如果设置了 `schedule_provider_name`，优先使用该 Provider。
2. 如果该 Provider 不可用（不存在或获取失败），则尝试 `schedule_fallback_provider_name`（如果设置了）。
3. 如果备用也不可用，则报错（不会自动回退到全局默认模型，方便排查）。
4. 若 `schedule_provider_name` 为空，则直接使用 `schedule_fallback_provider_name`（若存在），否则使用 AstrBot 全局默认模型。

## 获取 OpenWeather API Key

1. 访问 [OpenWeather](https://openweathermap.org/) 注册账号
2. 在 API Keys 页面生成免费密钥：https://home.openweathermap.org/api_keys
3. 将密钥填入配置项 `weather_api_key`
4. 设置 `weather_location` 为城市英文名加国家代码，如 `Beijing,CN`

## v2.9.0 

- **新增备用模型支持**：日程生成时可配置首选和备用 Provider，首选失败自动切换备用。
- **新增重试间隔配置**：避免重试时无间隔疯狂请求，节省资源，提升稳定性。
- **修复模型静默回退问题**：现在如果指定模型不可用且未配置备用，会明确报错，不再偷偷使用全局默认模型。
- **提升日志可读性**：打印当前使用的 Provider 名称和重试等待时间。
