# Humanoid Core - 拟真生活状态引擎 (v2.6.1)

**一句话概括**：让人工智能拥有"身体"、"生活感"、"情绪"和"场景意识"的中轻量插件。

---

## 🚀 功能一览

| 模块 | 说明 |
|------|------|
| **动态日程** | 每日由大模型生成 24 小时生活日程，支持粒度调节（灵活/整点/半小时） |
| **精力系统（拟人化）** | 随机波动、午后微降（-2%）、每日保底，支持倍率调节，无惯性偏向 |
| **生理周期** | 模拟经期/卵泡期/排卵期/黄体期，支持完整/简洁两种描述风格 |
| **情绪系统** | 三维度（好感度/亲近欲/攻击性），用户交互驱动，精力与生理周期调制，50+情绪标签 |
| **情绪日志** | 自动记录情绪关键变化（好感度/亲近欲/攻击性），支持查看历史波动 |
| **多人格系统** | 支持两个人格配置（默认人格 + 切换目标人格），用户可手动切换或定时自动轮换（含自定义时间）<br>**新增**：临时切换带到期时间，支持 `2h`、`30m`、`18:00` 格式，到期自动恢复默认人格（可全局开关） |
| **实时天气** | 通过 OpenWeather 获取当前天气，作为聊天背景 |
| **三种聊天模式** | 完整注入 / 低侵入 / 纯情绪，自由切换 |
| **环境感知** | 可选择插件仅在私聊、仅在群聊或全部生效 |
| **聊天感知** | AI 能自动识别当前是群聊还是私聊，语气自动适配（可开关） |
| **星期几感知** | AI 知道今天星期几，日程生成和对话语境更贴合，`/时间` 也显示星期几 |
| **动态时区绑定** | 所有时间逻辑（日程、精力、午后节律）均基于配置的 `timezone_city`，不再硬编码 UTC+8 |
| **城市与地区支持** | 覆盖中国所有地级市、俄罗斯主要城市（莫斯科/加里宁格勒/叶卡捷琳堡等）、日本主要城市（东京/大阪/札幌等） |
| **城市感知** | AI 会知道自己所在的默认城市及当前时间 |

## ✨ v2.6.1 更新内容

- **修复情绪更新频繁超时问题**：
  - 超时时间从 10 秒增加到 30 秒（可通过 `mood_update_timeout` 配置调整）。
  - 情绪更新改为后台异步执行，不再阻塞消息回复。
- **新增配置项**：`mood_update_timeout`（默认 30 秒）。
- **临时人格切换增强**：`/切换人格 人格名 [时间]` 现支持 `2h`、`30m`、`18:00` 格式，到期自动恢复默认人格，由 `persona_auto_recover_enabled` 全局控制。

---

## ✨ v2.5.2 更新内容

- **多人格配置简化**：不再需要填写 JSON 数组，改为四个独立文本字段：
  - `persona_default_name` + `persona_default_description`：默认人格
  - `persona_switch_name` + `persona_switch_description`：切换目标人格
- **用户一目了然**：名称和描述分开，知道自己在填什么

---

## ✨ v2.5.1 更新内容

- **新增自定义时间切换模式**：
  - `persona_switch_mode: "custom"` + `persona_switch_custom_time: "HH:MM"`
  - 支持在每天的指定时间自动轮换人格（如 `08:00`、`18:30` 等）

---

## ✨ v2.5.0 更新内容

- **新增情绪日志系统**：
  - 自动记录情绪关键变化（好感度/亲近欲/攻击性变化超过阈值时触发）
  - 每个用户独立存储，最多保留 30 条（可配置）
  - 新增指令 `/情绪日志` 查看最近 10 条记录
- **新增多人格系统**：
  - 支持两个人格配置（默认 + 切换目标）
  - 手动或定时自动切换（`manual`/`daily`/`hourly`/`custom`）

## 配置项说明

### 多人格相关配置

| 配置项 | 说明 |
|--------|------|
| `persona_enabled` | 是否启用多人格系统 |
| `persona_default_name` | 默认人格名称 |
| `persona_default_description` | 默认人格描述 |
| `persona_switch_name` | 要切换的目标人格名称 |
| `persona_switch_description` | 目标人格描述 |
| `persona_switch_mode` | 切换模式：manual/daily/hourly/custom |
| `persona_switch_custom_time` | 自定义切换时间（仅 custom 模式），格式 HH:MM |
| `persona_reset_mood_on_switch` | 切换时是否重置情绪值 |
| `persona_auto_recover_enabled` | **新增**：是否允许临时切换后自动恢复（关闭后忽略到期时间） |

### 情绪相关配置（新增）

| 配置项 | 说明 |
|--------|------|
| `mood_update_timeout` | 单次情绪更新请求超时时间（秒），默认 30.0 |

> **示例**：默认人格填"温柔"，描述"说话轻声细语"；切换目标填"傲娇"，描述"嘴上不饶人心软"。启用后，用户可通过 `/切换人格 人格名 2h` 切换并自动恢复。
