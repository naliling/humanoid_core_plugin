# Humanoid Core - 拟真生活状态引擎 (v2.6.3)

一个有自己的时间、会累会恢复、情绪会积累的AI生活引擎。

---

## 它是什么

- 每天有不一样的日程安排（由大模型生成）
- 精力会随着活动消耗和恢复（经期消耗更快，卵泡期更慢）
- 有生理周期（6个阶段，描述只提能量水平）
- 情绪会随着对话变化（好感度、亲近欲、攻击性）
- 会记住你让它生气的时刻（情绪日志）
- 可以切换人格（温柔、傲娇等，手动或定时）
- 天气会影响它的状态（接入OpenWeather）
- 知道今天是星期几，知道你所在城市的当前时间
- 你可以设定它对你的称呼

---

## 你实际用起来会发现什么

- 你问“在干嘛”，它真的有事在干——今天工作、下午散步、晚上休息，每天不一样
- 聊到傍晚它说“有点累了”，那是真的算出来累了，不是预设台词
- 下雨天它语气闷，晴天它轻快
- 连着几天对它冷，它好感度会掉，会变得客气，甚至疏远
- 你可以让它换人格——今天温柔明天傲娇，到点自动换也行
- 它知道今天是周几，知道你城市现在几点

---

## 功能列表

| 模块 | 它在做什么 |
|------|-----------|
| **动态日程** | 每天用大模型生成24小时安排，工作/学习/休息/睡觉都有具体时间点 |
| **精力系统** | 早上恢复，白天消耗，经期消耗更快，卵泡期更慢，深夜剩5% |
| **生理周期** | 分了6个阶段，描述只提“能量高不高”，不提具体症状 |
| **情绪系统** | 好感度/亲近欲/攻击性，你每说一句话都在微调它的态度 |
| **情绪日志** | 它会记下“上次你惹我生气了”这种时刻 |
| **多人格** | 两个人格配置，手动切或定时切，临时切可以设自动恢复时间 |
| **实时天气** | 接入OpenWeather，天气成为它日常状态的一部分 |
| **聊天模式** | 三种档位，你可以控制它“知道你多少状态” |
| **环境感知** | 私聊/群聊/全开都行，它会根据场景调语气 |
| **星期/时间感知** | 它知道今天是星期几，知道你在的城市几点 |
| **自定义昵称** | 你让它叫你什么，它就一直叫 |

## 配置项

### 多人格配置

| 配置 | 说明 |
|------|------|
| `persona_enabled` | 开不开启多人格 |
| `persona_default_name` | 默认人格名字 |
| `persona_default_description` | 默认人格描述 |
| `persona_switch_name` | 目标人格名字 |
| `persona_switch_description` | 目标人格描述 |
| `persona_switch_mode` | manual/daily/hourly/custom |
| `persona_switch_custom_time` | custom模式下每天几点切，格式HH:MM |
| `persona_reset_mood_on_switch` | 切人格时重置情绪吗 |
| `persona_auto_recover_enabled` | 临时切换到期后自动恢复默认人格 |

### 情绪配置

| 配置 | 说明 |
|------|------|
| `mood_update_timeout` | 情绪更新请求超时秒数，默认30秒 |
