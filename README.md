# Humanoid Core - 拟真生活状态引擎 (v2.1.9)

**一句话概括**：让人工智能拥有"身体"和"生活感"的中轻量插件。

---

## 🚀 功能一览

| 模块 | 说明 |
|------|------|
| **动态日程** | 每日由大模型生成 24 小时生活日程，支持粒度调节（灵活/整点/半小时） |
| **精力系统（拟人化）** | 随机波动、午后微降（-2%）、每日保底，支持倍率调节，无惯性偏向 |
| **生理周期** | 模拟经期/卵泡期/排卵期/黄体期，支持完整/简洁两种描述风格 |
| **实时天气** | 通过 OpenWeather 获取当前天气，作为聊天背景 |
| **三种聊天模式** | 完整注入 / 低侵入 / 纯情绪，自由切换 |
| **环境感知** | 可选择插件仅在私聊、仅在群聊或全部生效 |
| **状态指令** | `/你的状态` 查看精力（含拟人描述）、生理、天气、日程概要 |
| **时间查询（所有用户）** | `/时间 城市` 查询中日俄主要城市当前时间 |
| **昵称设置** | `/叫我 昵称` 让 AI 记住你的称呼 |
| **管理员查看昵称** | `/查看所有昵称` 列出所有用户设置的昵称 |
| **重置状态（管理员）** | `/重置状态` 一键恢复精力至80、生理周期重新计算 |
| **帮助指令** | `/拟人帮助` 列出所有可用命令 |
| **城市感知** | AI 会知道自己所在的默认城市及当前时间 |

## ✨ v2.1.9 更新内容

- **取消精力惯性**：恢复与消耗完全由日程 `energy_rate` 决定，不再对高低精力做偏向。
- **削弱午后节律**：从 -5% 降至 -2%，几乎无感。
- **每日保底恢复**：若精力低于 30，每日凌晨自动拉回至 30，防止归零。
- **时间指令全员开放**：`/时间` 指令不再限制管理员，所有用户均可查询城市时间。

## 核心特性

1. **多用户全局状态一致**  
   所有用户共享同一个物理世界的状态推演（精力、天气、日程、生理周期）。

2. **人格驱动的动态日程生成（LLM驱动 + 备用模板）**  
   - 根据配置中的 **角色人格（`character_personality`）** 生成符合人设的日程。
   - 默认调用大模型（可指定 Gemini、GPT 等）每日自动生成全新的 24 小时生活日程。
   - **灵活的时间粒度**：支持小时、半小时、20分钟、15分钟等。
   - 内置 **3次重试机制** + **超时控制**（60秒），自动重试。
   - 若模型调用失败，自动降级至**基于日期哈希轮换的多套备用模板**。

3. **拟人化精力系统（v2.1.9 优化）**  
   - 随时间与活动自然变化，支持倍率调节（0.5x/1x/2x/3x）。
   - **取消惯性**：恢复与消耗完全由日程决定，不再偏向消耗。
   - **每日随机波动**：模拟生理节律微小变化（±2%）。
   - **午后节律**：13:00~15:00 精力自然下降 **2%**（原为5%）。
   - **每日保底30**：防止精力归零。
   - 提供 5 档拟人描述，用于语气微调。

4. **隐式生理周期（后台无感推算）**  
   - 后台零点自动跨天计算，前台仅隐式呈现生理体验描述。
   - 周期起始日基于日期确定性生成，**重启 Bot 不会随机跳跃**。
   - 支持完整/简洁两种描述风格。

5. **三种聊天模式**  
   - **完整注入**：注入天气、位置、日程、精力、周期、时间等全部信息。
   - **低侵入**：注入精力、情绪、周期、时间，不注入日程和位置。
   - **纯情绪**：仅注入精力和情绪倾向。

6. **环境感知**  
   可选择插件仅在私聊、仅在群聊或全部生效，灵活适配不同场景。

7. **实时配置加载**  
   在 AstrBot 网页后台保存配置后，下一条消息立刻生效，无需重启 Bot。

8. **查看日程指令**  
   任意用户发送 `查看日程`，即可查看当天的完整日程表。

9. **重置日程指令（管理员）**  
   管理员发送 `重置日程`，可强制立即重新生成今日日程。需先在配置中设置 `admin_qq` 列表。

10. **重置状态指令（管理员）**  
    管理员发送 `重置状态`，可一键恢复精力至 80，并重新计算生理周期（基于当前日期），保留昵称和日程等数据。

11. **状态、时间、昵称、帮助等便捷指令**（详见上方功能一览）。

## 天气配置说明

天气接口平台：https://openweathermap.org

1. 注册账号，进入 API Keys 页面复制32位密钥。
2. 城市填写格式：`城市英文,国家码`，例如 `Beijing,CN` / `Moscow,RU`。
3. 免费额度足够个人使用，国内直连无需代理。

## 常见问题

**Q：如何让日程符合我的角色设定？**  
A：在插件配置中从 `character_personality` 下拉列表选择一个人格。描述越具体，日程越贴合人设。

**Q：v2.1.9 精力系统改了什么？**  
A：取消惯性（恢复与消耗完全由日程决定），午后节律从 -5% 改为 -2%，每日保底恢复至30，防止归零。

**Q：如何调节精力变化速度？**  
A：在 `energy_decay_rate` 中选择 0.5（半速）、1（正常）、2（双倍）或 3（三倍）。

**Q：如何让插件只在私聊或只在群聊生效？**  
A：在 `environment_mode` 中选择 `both`（全部）、`private`（仅私聊）或 `group`（仅群聊）。

**Q：日程一直不变化，总是同一套？**  
A：检查 `use_llm_schedule` 是否为 `true`；若为 `true` 但日志提示"无可用 Provider"，请确保已正确配置大模型。

**Q：如何重置今天的日程？**  
A：由管理员发送 `重置日程` 即可。请确保在 `管理员QQ列表` 中填写了你的 QQ 号。

**Q：如何重置精力和生理周期？**  
A：由管理员发送 `重置状态`，精力将恢复至 80，生理周期根据当前日期重新计算。

**Q：生理周期描述不准确或跳跃？**  
A：当前版本已修复周期日期的确定性生成和跨天更新锁保护，重启 Bot 不再随机重置。

**Q：天气无法获取？**  
A：请确认 `天气api_key` 填写正确、`weather_location` 格式为 `城市,国家码`（如 `Beijing,CN`），并检查网络连通性。

**Q：时间查询支持哪些城市？**  
A：支持中国（含各省会/直辖市及主要地级市）、俄罗斯（全部85个联邦主体）、日本（主要城市）。具体列表请参见上方 **“支持的城市列表”** 章节。
