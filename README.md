# Humanoid Core - 拟真生活状态引擎 (v2.8.0)

一个有自己的时间、会累会恢复、情绪会积累的AI生活引擎。  
联系作者：3881756548（重度依赖用户反馈与建议）

---

## 它是什么

- 每天有不一样的日程安排（由大模型生成）
- 精力会随着活动消耗和恢复（经期消耗更快，卵泡期更慢）
- 有生理周期（6个阶段，描述只提能量水平）
- 情绪会随着对话变化（好感度、亲近欲、攻击性）
- 会记住你让它生气的时刻（情绪日志）
- 可以切换人格（温柔、傲娇等，手动或定时）
- 天气会影响它的状态（接入OpenWeather）
- 知道今天是星期几，知道你所在城市的当前时间
- 你可以设定它对你的称呼
- 心情标签（如"疲惫但开心"），直观显示当前情绪
- 社交能量（影响回复热情，长时间对话会消耗）
- 夜间睡眠模式（深夜回复变短或主动提示休息）
- 热重载配置（/重载配置 指令，无需重启插件）
- 调试模式（输出详细日志，便于排查问题）
- 节日感知（内置公历节日 + 用户自定义，自动融入上下文）

## 功能列表

| 模块 | 它在做什么 |
|------|-----------|
| **动态日程** | 每天用大模型生成24小时安排，工作/学习/休息/睡觉都有具体时间点 |
| **精力系统** | 早上恢复，白天消耗，经期消耗更快，卵泡期更慢，深夜剩5% |
| **生理周期** | 分了6个阶段，描述只提"能量高不高"，不提具体症状 |
| **情绪系统** | 好感度/亲近欲/攻击性，你每说一句话都在微调它的态度 |
| **情绪日志** | 它会记下"上次你惹我生气了"这种时刻 |
| **心情标签** | 根据情绪数值和精力生成可读标签（如"疲惫但开心"） |
| **社交能量** | 每条消息消耗，长时间不聊恢复，影响回复热情 |
| **夜间模式** | 深夜时段回复变短，或主动提示休息 |
| **多人格** | 两个人格配置，手动切或定时切，临时切可以设自动恢复时间 |
| **实时天气** | 接入OpenWeather，天气成为它日常状态的一部分 |
| **聊天模式** | 三种档位，你可以控制它"知道你多少状态" |
| **环境感知** | 私聊/群聊/全开都行，它会根据场景调语气 |
| **星期/时间感知** | 它知道今天是星期几，知道你在的城市几点 |
| **自定义昵称** | 你让它叫你什么，它就一直叫 |
| **热重载配置** | 修改配置后通过指令重载，无需重启插件 |
| **调试模式** | 输出详细日志，方便排查问题 |
| **节日感知** | 内置元旦、情人节、劳动节、国庆节等公历节日，用户可自定义补充 |

## 指令列表

### 用户指令（所有人都能用）

| 指令 | 说明 |
|------|------|
| `/你的状态` | 查看精力、生理、天气、日程、情绪、人格、心情标签、社交能量 |
| `/好感度` | 查看情绪数值和当前标签 |
| `/情绪详情` | 查看详细情绪（含基线和轮次） |
| `/情绪日志` | 查看最近10条情绪波动记录 |
| `/时间 城市` | 查看某个城市的当前时间（含星期几和节日） |
| `/叫我 昵称` | 设置AI对你的称呼 |
| `/切换人格 人格名 [时间]` | 切换人格，可设自动恢复时间（2h/30m/18:00） |
| `/查看人格` | 查看当前人格和可用人格列表 |
| `/人格详情 [名称]` | 查看某个人格的详细设定 |
| `/查看日程` | 查看今天的完整日程表 |
| `/拟人帮助` | 显示本帮助 |

### 管理员指令（需要配置 `admin_qq`）

| 指令 | 说明 |
|------|------|
| `/重置日程` | 强制重新生成今天的日程 |
| `/重置状态` | 重置精力至80，社交能量至100，生理周期重新计算 |
| `/重置情绪` | 重置情绪至初始值 |
| `/设置好感度 数值` | 手动设置好感度（0-100） |

| `/查看所有昵称` | 查看所有用户设置的昵称 |
| `/重载配置` | 热重载插件配置，无需重启 |

## 配置项

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `debug_mode` | 调试日志开关 | `false` |
| `social_energy_recovery_per_minute` | 每分钟恢复量 | `0.2` |
| `mood_update_timeout` | 情绪分析超时（秒） | `120` |
| `weather_api_key` | OpenWeather API Key | `""` |
| `weather_location` | 城市英文名，如 Beijing,CN | `Heyuan,CN` |
| `timezone_city` | 默认时区城市 | `广州` |
| `admin_qq` | 管理员QQ列表 | `[]` |

## 获取 OpenWeather API Key

1. 访问 [OpenWeather](https://openweathermap.org/) 注册账号
2. 在 API Keys 页面生成免费密钥：https://home.openweathermap.org/api_keys
3. 将密钥填入配置项 `weather_api_key`
4. 设置 `weather_location` 为城市英文名加国家代码，如 `Beijing,CN`

## v2.8.0更新
